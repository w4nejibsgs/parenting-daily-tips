# 西宁正规医院冷冻卵子一年保存费用是多少？

> 更新时间：2026-09-10 (UTC+8)

我本人今年30岁，已婚，而且已育有一女，三岁多，暂时不打算要二胎，然后我本人目前身体一切健康，但是出于各方面考虑，主要考虑到独生子女的各种问题，所以之后还是有可能再生的，只是目前不会生，所以就想要去正规医院进行卵子冷冻保存，想问问西宁的姐妹，你们知道冷冻卵子的费用要多少吗？一年保存费贵不贵？

符合卵子冷冻条件的患者可以在西宁正规医院进行卵子冷冻保存，而在西宁冷冻卵子的费用是一次1500元，卵子保存费用是10元一日，冷冻卵子一年的保存费就是3650元，不过这是一管卵子的年保存费，因为通常冷冻处理一次卵子是2-4个卵子为一管，所以说，冷冻卵子的费用和年保存费具体多少就要看卵子的总数量。

据了解，目前西宁正规医院中有两家医院（青海红十字医院和青海省人民医院）可以冷冻卵子，但是要符合冻卵条件的女性才可以前往进行生育力保存。而这里根据青海红十字医院官网公布的医疗价格为大家整理了西宁冷冻卵子整个过程涉及到的相关费用，大家可以参考了解：

- 1. 检查费：检查项目比较多，通常有抗缪勒管激素测定300元一项，卵泡刺激素（FSH）测定50元一项，人绒毛膜促性腺激素（HCG）测定50元一项，经阴道妇科B超检查40元一次，染色体核型分析150元一次，染色体分析300元一次，梅毒螺旋体抗体（抗TP）测定60元一次，人免疫缺陷病毒抗体（抗HIV）测定60元一次等等，检查总费用一般要2000元左右；
- 2. 促排费：每个患者卵巢功能不同，促排一个周期的用药量以及时长都不一样，一般用到的促排药有重组人促卵泡激素注射液1460.75元一支，注射用重组人促卵泡激素（国产）231元一支，促排药物费用普遍需要6000-10000元不等；
- 3. 取卵手术费：经腹取卵术是1400元一次，经腹腔镜取卵术是1900元一次，除了手术费，还有麻醉、卫生材料费、临床操作B超引导等等费用，一共大概要6000元左右；
- 4. 卵子冷冻以及保存费：卵子冷冻费用是1500元一次，也就是冷冻一管卵子的费用，而卵子冷冻保存费用是10元一日，这部分费用具体多少要看卵子的数量，一管卵子一年的保存费大概就是3650元。
在西宁冷冻卵子的总费用主要就是包括这四大部分，虽然卵子的冷冻费和保存费并不贵，但是加上其他的相关费用，总的花费一般还是要2万元左右。
